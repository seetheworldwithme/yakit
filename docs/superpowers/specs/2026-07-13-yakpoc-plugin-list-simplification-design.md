# 漏洞检测插件列表简化设计

## 目标

在漏洞检测的插件执行表单中移除插件分组列表顶部的全部筛选与统计控件，并使该列表的内容宽度与扫描目标输入框一致。

## 范围

- 移除关键词搜索框。
- 移除全选、Total、Selected 与清空控件。
- 保留分组卡片本身的勾选及展开能力。
- 保留展开后的插件明细和既有查询逻辑。

## 实现设计

`PluginGroupByKeyWord` 不再渲染筛选区 JSX。分组列表继续使用既有的初始数据查询，因此不删除与搜索相关的状态和请求逻辑，避免影响任务恢复或缓存数据。

内联场景由 `.inline-plugin-group` 覆盖宽度，使它填满 antd 表单项的 wrapper 内容区域；该 wrapper 与扫描目标输入框共用 `wrapperCol={{ span: 18 }}`，因此两者将保持一致。

## 验收标准

- 漏洞检测页不再显示关键词搜索、全选、Total、Selected 或清空。
- 分组卡片占满扫描目标输入框的内容宽度，并保持两列布局。
- 勾选分组、展开分组、查看插件明细与开始执行仍可用。
- 不影响其他页面的插件分组列表。
