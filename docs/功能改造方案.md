# 前端功能改造方案（深蓝工作台 · 代号待定）

> 本文档是后续改造的**唯一事实源**。方向已与负责人对齐：
> - **目标**：基于「功能要求.xlsx」保留的能力，把页面骨架与布局彻底重塑，使新版在外壳、版式、命名、结构指纹上**与原版 yakit 读不出同源**。
> - **外壳**：A · IDE 工作台（左侧域 rail + 中央多页签工作区）。
> - **视觉**：I · 深空青蓝（纯深底 + 青蓝主色 + 高数据密度 + 微光描边）。

---

## 一、硬约束

1. **只动表达层，不动业务**：state / 接口 / 事件 / 路由 / IPC 全保留，只换 IA / 版式 / 视觉 / 命名 / 文件组织。
2. **「看不出同源」= 四层全做**：① 信息架构 ② 页面骨架 ③ 视觉语言 ④ 结构指纹。只换色 = 不过关，第 ④ 层做重。
3. **全变体统一**：社区版 / 企业版 / IRify / Memfit 都按本方案改，非仅社区版。
4. 改造期间业务可正常使用：隐入口 ≠ 删功能，确无引用再整删。

## 三、第 1 步 · 信息架构（IA）

### 3.1 核心切割：从「扁平顶级 tab」→「5 域 + 左 rail」

原版 yakit 是「所有工具平铺成顶级 tab」（类 Burp），这是最重的指纹。新版改为 **5 个能力域**，按攻击者工作流分组，导航形态换成左固定 activity rail。

| 域 | 中文 | 含义 | rail 图标语义 |
|---|---|---|---|
| **Recon** | 侦收 | 理解流量与数据 | 雷达 / 档案 |
| **Strike** | 进攻 | 主动干预流量 | 交叉剑 / 闪电 |
| **Detect** | 检测 | 自动化发现 | 靶心 / 扫描线 |
| **Extend** | 扩展 | 能力扩展（脚本/插件/字典） | 拼图 / 齿轮 |
| **Govern** | 治理 | 协作与管控 | 盾牌 / 仪表 |

### 3.2 左 rail 内容（按域展开二级模块列表）

**侦收 Recon**
- 流量档案（← History）
- 流量分析（← 流量分析器，作为档案内视图）
- 编解码台（← Codec）
- 差异比对（← 数据对比）

**进攻 Strike**
- 实时劫持（← MITM 交互式劫持）
- 报文构造台（← Web Fuzzer）
- WS 构造台（← Websocket Fuzzer）
- 凭证爆破（← 弱口令检测）
- 批量投递（← 批量执行）
- 反连接收（← DNSLog / 反连服务器 / 端口监听器，合并一页多模式）

**检测 Detect**
- 资产测绘（← 端口/指纹扫描）
- 漏洞巡检（← 专项漏洞检测）
- 风险台账（← 漏洞与风险）
- 报告中心（← 报告）
- 误报记录（← 误报记录）

**扩展 Extend**
- 脚本引擎（← Yak Runner）
- 本地插件（← 插件）
- 插件市场（← 插件仓库）
- 字典库（← 字典管理）
- 配置管理（← 配置管理：代理/热加载/字典）

**治理 Govern**
- 态势总览（← 首页）
- 项目管理
- 团队与权限（← 账户/角色/信任列表）
- 采集上报（← 漏洞采集，企业版）

### 3.3 命名体系原则

- **全部模块换名**，不复用「Web Fuzzer / MITM / Codec / Yak Runner」等原版称谓（这些是强指纹）。
- 中文优先（产品面向国内），配英文 codename 供代码层命名空间用。
- 代码层命名空间统一前缀（建议 `sw-` = Sentinel Workbench，或另定），替换原 `layout-` / 零散类名。

```
└───┴──────────────────────────────────────────────────────┘
```

**区块定义**
- ① **顶栏（48px）**：左侧 5 域 tab 切换；中部项目选择器；右侧连接状态 / 全局搜索 / 设置。取代原版「顶级工具 tab 条」。
- ② **左 rail（200px，可折叠到 56px）**：当前域的模块导航；与顶栏联动（切域 → rail 内容换）。
- ③ **多页签条**：模块可多开，每个 tab = 一个工作面实例；支持固定 / 临时 / 拖拽。
- ④ **工作面**：各页面按统一模板（见六）填充。
- ⑤ **状态栏（28px，新增）**：引擎状态 / 代理状态 / 后台任务计数 / 版本。原版无此栏，是差异化性状。

**与原版的关键差异**：原版是「顶级 tab = 工具，无域分组，无左 rail，无状态栏」；新版是「域 → 模块 → 工作面」三级 + 状态栏。导航骨架完全不同。

- 三栏型：树 / 列表 / 详情（项目管理 / 团队权限）

- 单栏编辑型：编辑器为主（脚本引擎 / 编解码台 / 差异比对）

## 七、结构指纹打散策略（第 ④ 层 · 重点）

> 这一层是「换皮」与「真不同」的分水岭。视觉/版式做完后，若 DOM 标签序列与原版高度重合，仍会被判同源。

1. **语义化标签**：`div` 海 → `section / main / nav / aside / article / header / footer`。外壳、rail、工作面、状态栏各用对应语义标签。
2. **class 成体系重命名**：统一前缀（如 `sw-rail`、`sw-workbench`、`sw-statusbar`、`sw-forge`），替换原 `layout-` / 各页零散类名；**非逐字母替换**，而是按新命名空间重建。
3. **组件文件重排**：
   - 外壳从 `pages/layout/mainOperatorContent/` 迁到新目录（如 `pages/shell/`），内部拆成 `Shell/TopBar/DomainRail/Workbench/StatusBar` 子组件。
   - 各页面按新域归属重新归档（如 `pages/strike/forge/`、`pages/recon/archive/`），替换原 `fuzzer/` `hTTPHistoryAnalysis/` 等强指纹目录名。
4. **路由层重组**：`YakitRoute` 枚举值（字符串）是强指纹，新增一层「域/模块」路由映射，对外呈现新路径，内部兼容旧 key。
5. **栏位/容器互换**：主从左右 ↔ 上下、Tabs ↔ 步骤、列表 ↔ 网格 —— 每页至少一处与原版相反的排布。
