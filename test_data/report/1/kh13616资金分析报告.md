## 七、经营模式与涉案资金穿透研判

### （一）经营模式分析

基于前六章的分析，该账户的经营模式高度匹配**地下钱庄/非法换汇**模式，具体表现为：

1. **资金归集层**：xm1083通过30个同名关联账户和外部来源方（如xm734、xm405等）以现金存入和小额转账的方式将资金汇入kh13616核心账户。收入端以5千至5万区间的小额交易为主（占收入81.8%），呈现"蚂蚁搬家"式归集。其中现金收入占83.4%，说明客户多以现金方式交付资金。

2. **资金中转层**：kh13616作为核心过渡账户，负责整合来自多渠道的资金。账户资金周转率高达370.4，资金到账后快速转出，平均余额仅86.4万元但年交易量达数千万元。收支几乎完全平衡（差额仅0.22%），不承担资金存储功能，仅为过渡环节。

3. **资金分配层**：资金从核心账户集中输出至下游账户。最大接收方kh63621（xm1372）独占45,207,800.00元（占支出28.2%），其次kh65156等同名账户接收22,586,500.00元。分配方式以大额转账为主，支出端10万至50万区间占比52.9%。

4. **变现层**：支出端99.97%为现金交易，资金最终几乎全部以现金形式支取。结合2笔"换钱"关键词交易，可以判断该团伙的经营模式为：**收进人民币现金 → 账户过渡 → 现金支取/转账 → 完成换汇交割**。客户的资金以现金形式交付，经过短暂账户过渡后，以现金或转账形式输出至下游，完成地下钱庄的换汇交易。
