### 3.4 AI 首页推荐点击处理

**涉及文件：** `app/renderer/src/main/src/pages/ai-agent/aiChatWelcome/AIChatWelcome.tsx`

- 点击"工程化程序"标题（"更多"按钮）时：通过 `yakitBridge.shell.launchToolsApp('')` 启动 Tools 应用首页
- 点击具体工程化程序项（如"数据清洗"）时：通过 `onLaunchEngineeringProgram(v.name)` 调用跳转

核心代码逻辑：

```typescript
// 页面名称到 pageKey 的映射
const ENGINEERING_PAGE_MAP: Record<string, string> = {
  '数据清洗': 'clean',
  '资金穿透': 'penetration',
  '团伙画像': 'profile',
  '一键报告': 'report',
}

// 点击具体工程化程序项的回调
const onLaunchEngineeringProgram = useMemoizedFn((name: string) => {
  const pageKey = ENGINEERING_PAGE_MAP[name]
  if (pageKey && (window as any).yakitBridge?.shell?.launchToolsApp) {
    ;(window as any).yakitBridge.shell.launchToolsApp(pageKey).catch((err: any) => {
      console.error('启动 Tools 应用失败:', err)
    })
  }
})

// 在推荐列表中，工程化程序使用独立的点击处理
onCheckItem={
  aiItem.type === '工程化程序'
    ? (v) => onLaunchEngineeringProgram(v.name)
    : (v) => onCheckItem(v, aiItem.mentionType)
}
```

### 3.6 Electron 主进程处理（关键：实际启动逻辑）

**涉及文件：** `app/main/handlers/launchTools.js`（新增文件）

这是工程化程序点击后能跳转到 Web 页面的核心，包含完整的三端（Mac/Win/Linux）支持：

**工作模式（两种，优先 Web 模式）：**

1. **Web 模式**（默认）：通过浏览器打开 `http://localhost:18888/#/{pageKey}`
   - 地址可通过环境变量 `TOOLS_WEB_URL` 覆盖
   - URL 拼接规则：`${TOOLS_WEB_URL}/#/${pageKey}`
   - 例如：点击"数据清洗" → 打开 `http://localhost:18888/#/clean`

2. **桌面模式**（回退）：启动独立的 Tools Electron 桌面应用
   - 通过 `--page={pageKey}` 命令行参数传递页面
   - 支持的应用名：`jztools`、`anti-fraud-workbench`

**合法的 pageKey 值：** `clean`、`penetration`、`profile`、`report`（空字符串打开首页）

**需要在 Electron 主进程入口注册此 handler：**
```javascript
// 在 app/main/index.js 或类似入口中引入
require('./handlers/launchTools')(win, getClient)
```

**页面与 pageKey 对应关系：**
| 页面名称 | pageKey | Web URL |
|---------|---------|---------|
| （首页） | `''` | `http://localhost:18888/` |
| 数据清洗 | `clean` | `http://localhost:18888/#/clean` |
| 资金穿透 | `penetration` | `http://localhost:18888/#/penetration` |
| 团伙画像 | `profile` | `http://localhost:18888/#/profile` |
| 一键报告 | `report` | `http://localhost:18888/#/report` |
